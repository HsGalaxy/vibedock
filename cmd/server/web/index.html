直接登录 Provider

登录在 Provider 官方页面完成。VibeDock 不接收 Provider 密码，也不会把 setup-token 当作网页登录。

CodexOpenAI OAuth 授权 · 凭据保存在这个账号的独立目录
  1. 打开 OpenAI 官方授权页面并完成登录。
  2. 浏览器返回 http://localhost:1455/auth/callback 后，复制地址栏中的完整地址；页面无法打开不影响授权。
  3. 粘贴完整地址并提交。
OpenAI 返回地址必须包含 code 和 state 参数
